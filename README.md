## A SEARCH ENGINE FOR CODEING QUESTION THAT GIVE THE LINKS OF THE QUESTION WITH RELEVANT KEY WORD 
# 🚀 Coding Questions Search

A fast and user-friendly web application that helps developers search, browse, and practice coding interview questions from a centralized collection.

Whether you're preparing for coding interviews, improving your DSA skills, or revising common problems, this application makes finding questions quick and effortless.

---

## ✨ Features

- 🔍 Instant search for coding questions
- 📂 Browse questions efficiently
- ⚡ Fast and responsive interface
- 📱 Mobile-friendly design
- 🎯 Helps with interview preparation
- 🖥️ Clean and intuitive UI

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Namankapooor/Coding-questions-search.git
```

### 2. Navigate to the project

```bash
cd Coding-questions-search
```

### 3. Create a virtual environment (Optional)

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
